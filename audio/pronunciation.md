# Pronunciation guide — drug names

Dual purpose: (1) human pronunciation reference, (2) substitution table for TTS pipelines — replace the written name with the respelling before synthesis if the engine mangles it. CAPS = stressed syllable.

Stem shortcuts (say these right and most generics follow): **-mab** = "mab", **-tinib** = "TIH-nib", **-ciclib** = "SY-klib", **-glutide** = "GLOO-tide", **-tide** = "tide", **-cel** = "sell", **-zomib** = "ZOH-mib", **-xaban** = "ZA-ban" or "KSA-ban".
